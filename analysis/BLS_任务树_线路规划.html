三、剧情怎么写（法则 + 逐线样例，可直接粘）

剧情不是"写一段漂亮话"，是三层东西：① 节点文案（title 4–8 字 + desc 60–110 字）② 标题之间的用词分工（一列读下来像一章，不像五个同义词）③ 可选：完成节点时弹一个风味事件（country_event，原版实证 99_Hansa_Missions.txt:83；本项目骨架见 events/ALC_mission_events.txt 全 14 行）。

3.1 七条法则

#法则为什么
1三句式：地景一句 → 人的动作一句 → 代价/结果一句第一句让玩家看见海，第二句告诉他干了什么，第三句告诉他花了什么。缺第三句就变成口号。
2主语永远是集体：守岸人 / 黑海岸 / 议会 / 舰队 / 系统EU4 的 desc 是史书体，出现「你」立刻掉出世界观。
3不写数值、不写「完成任务」「提高 X%」；真要提示数值就交给 trigger 的 tooltipdesc 是叙事面板，不是收益清单。攻略腔一出现，整棵树的气质就散了。
4每段 desc 至少一个具体地名或物件（坤甸的河口 / 帝汶的望楼 / 舵轮改的冠）具体才有画面；通稿感的根因是全是抽象名词。
5一列之内时间线要推进：早期写「立」，中期写「守」，末期写「传」5 个标题连起来应该像一章，而不是 5 个并列的同义词。
6允许一句克制的冷幽默，禁止热血口号与感叹号连击黑海岸的性格是"守"不是"燃"；一个「反正木头在这片海岸上不值钱」胜过十句豪言。
7色彩：§Y 只标唯一关键数字/地名一次，§G 标永久授予，§R 只给负面整段刷色 = 没有重点，且中文编码后极易溢出按钮宽度。

3.3 逐线样例（title / desc，可直接进 decode_localisation）

线 · 节点文案
经济 1潮声市集
坤甸的河口每天涨两次潮，船也跟着来两次。守岸人把税关设在潮水能打到的地方，让每一担香料都得先向黑海岸报一声名字。集市散了，账册还亮着灯。
经济 2不问来路的灯
黑海岸的商船不挂旗号，只挂灯。灯亮着，说明这条水路今晚归守岸人管。马六甲的海图因此被重画了一遍——画的不是海岸，是灯。
经济 3香料寻迹
香料群岛的芬芳是海商的梦。守岸人沿着气味往东，先在帝汶的礁石上立了第一座望楼，再把望楼连成线。线以内的产地，从此只认一种秤。
经济 4海峡锁钥
马六甲海峡窄得像一道伤口。谁按住它，谁就能让整片东方的血往自己这边流。黑海岸没有封锁它，只是把两端的灯塔都换成了自己人——船照样过，只是过的时候要低头。
经济 5黄金商路
金子不是挖出来的，是顺着潮水漂来的。当账房先生们发现国库的银箱要换更大的，守岸人只是把旧箱子劈了当柴——反正木头在这片海岸上不值钱。
宗教 1屋檐下加一盏灯
婆罗洲的旧神住在河口与树根里。守岸人没有拆他们的庙，只在庙的屋檐下挂了一盏灯。灯亮过三个雨季，村民便忘了该向谁磕头——他们只记得灯。
宗教 2多出来的席位
教廷的席位按城分配，不按海。黑海岸的使者带着一箱湿透的海图走进议事厅，把图摊开：这些岛，这些礁，这些连名字都没有的岸，都归我们守。席位于是多了一张。
宗教 3答应一声
护教者不是头衔，是债。当异端的船烧到邻国的港口，黑海岸的舰队已经在那儿了——不为土地，只为让那些还肯听潮声的人知道，有人答应过。
宗教 4同一个回声
全境的庙里终于只响一种钟。守岸人不强迫谁改口，只是让旧钟慢慢锈掉；锈到某一天，人们发现新钟的声音和潮水是一个调子。
扩展 1向海之外
海图的最东边曾经画着一条龙。守岸人的探险家沿着那条龙飞出去，回来时带了一张更长的图——图上没有龙，只有一串没名字的岛。
扩展 2第一块岸
殖民点建在一条没有淡水的小岛上。第一批去的人死了七个，活下来的把旗插在礁石最高的地方——不是因为那里好看，是因为涨潮时只有那里还露着。
扩展 3钟绳垂到水上
从婆罗洲出发的船，最远到过一片海水是黑色的地方。那里的人不会说黑海岸的话，但听得懂敲钟。守岸人于是在岸边留了一口钟，钟绳一直垂到水上。
扩展 4海之外的海
当殖民地连成一条线，黑海岸的地图上第一次出现了"外面"。守岸人议会为这件事吵了三天，最后决定：不画边界，只画航线。
军事 1不该有两个主人
婆罗洲是一整块，不该有两个主人。梦州的旗插在内陆的雨林里已经太久，久到连他们自己都忘了为什么插在那儿。守岸人替他们想起来了——用刀。
军事 2跨海进军
越过海峡，踏上马来半岛。守岸人不带辎重，只带盐和火药——这两样东西，半岛上都有。
军事 3半岛的骨头
马来半岛的河口一座接一座，像一排断掉的牙。黑海岸把它们一颗颗装回去，装到最后才发现，这颗头骨本来就是自己的。
军事 4婆罗洲收官
沙巴与库台的雨林里没有路，只有河。守岸人的军队沿河而上，把最后一个不属于黑海岸的营寨烧成了灰。灰落进水里，顺流到海——海认得这是谁的东西。
军事 5我们的海
从文莱到香料群岛，船要走四十天。这四十天里，每一处能下锚的地方都有一面黑旗。守岸人不再说"我们的海岸"，只说"我们的海"。
海军 1把河口挖深三尺
造船先造船坞。守岸人把八条河的河口都挖深了三尺，桩子打进淤泥里，一排排站着，像等命令的兵。
海军 2制海权
海战打的是风，不是船。黑海岸的水手从十二岁开始认风，认得比认字早。第一次炮响之后，风站在哪一边，就没有悬念了。
海军 3永夜舰队
重舰吃水深，进不了浅湾。守岸人还是造了——因为永夜来时，只有重舰的灯能亮到最后。那一夜海面上排开二十盏灯，像一条不肯沉的路。
海军 4潮汐壁垒
舰队多了，港就不够用。议会在珊瑚礁上凿出新港，涨潮时看不见，退潮时才露出来——敌人若来，先得学会看潮。
内政 1议会的第一盏灯
守岸人聚在文莱的旧仓库里议事，没有桌子，只有一张摊开的海图。争论到半夜，有人把灯芯剪短了一截——省下的油，够明天多派一条船。
内政 2要塞是用来谈的
要塞不是用来守的，是用来谈的。三门炮对着海，谈判桌上就多三分底气。守岸人从不在要塞里驻太多兵，只驻足够的旗。
内政 3候补的名字
继承人的名字要写进议会的册子里，才算法定。册子锁在灯塔底下，钥匙由三个人分持——一个人开不了，两个人开了也没用。
内政 4盐渍的冠
加冕那天没有雨。黑海岸的冠不是金子打的，是旧船的舵轮改的，边缘还留着盐渍。系统戴上它时说了一句话，风太大，没人听清。
内政 5潮声为证
到最后，守岸人不再需要向谁证明什么。潮水每天来两次，每次都照着同一个方向推——那是黑海岸的方向，从来没有变过。

3.4 坏例 → 好例（同一件事的两种写法）

写法文本诊断
攻略腔「完成此任务后，你将获得 +10% 贸易效率，并解锁新的任务。」把任务面板当说明书；世界观当场蒸发。
口号腔「提升贸易效率，让每一艘商船都满载而归！」没有地景、没有人、没有代价；三句里一句都不是画面。
好例「坤甸的河口每天涨两次潮，船也跟着来两次。守岸人把税关设在潮水能打到的地方，让每一担香料都得先向黑海岸报一声名字。集市散了，账册还亮着灯。」地名（坤甸）+ 机制（税关=贸易份额）+ 一句人话（灯还亮着）。玩家读完知道自己在干什么，也知道这活儿有多累。
