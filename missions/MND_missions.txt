# ============================================================
# 蒙德 MND 任务树
# slot = 列（1 最左 / 5 最右）；position = 行（1 最上）
# 关系：1_1→1_2；2_1→2_2→2_3；1_3 前置 2_2；3_1→3_2→3_3，3_3 另需 2_2
#
# 额外奖励写法（2026/11/27 统一为原版 1.35 的 complex_dynamic_effect 框架，
#   写法对齐 missions/TES_missions.txt:1932 与 IYS_missions.txt:2314）：
#     1_4 全国工坊 ≥15        → 「晨曦酒庄产业」
#     1_6 首都地区寺庙全满     → 「风神护佑」
#     1_7 主神为巴巴托斯       → 「芭芭拉的祷告」（⚠ first_limit 与 trigger 同条件，✓ 恒真）
#   要点：说明键 = <任务>_bonus_tt（自己写）；✓/✗ 两行由原版 BONUS_REWARD_YES / BONUS_REWARD_NO 提供；
#         奖励本体写在 first_effect 里 —— 框架末尾的 hidden_effect 才真正发放，tooltip 只负责显示；
#         多档「只能拿一个」用 complex_dynamic_effect，多档「满足几个给几个」用
#         complex_dynamic_effect_without_alternative（定义见原版 common/scripted_effects/00_scripted_effects.txt:5805 / :6017）。
# ============================================================
