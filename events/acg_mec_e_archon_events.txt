# 修正定义：common/event_modifiers/acg_mec_e_archon_modifiers.txt
# 本地化：decode_localisation/acg_mec_e_archon_l_english.yml（.t/.d/.a/.b 全套）

# ============================================================================
# 通用触发规范（30 件完全一致）
# ============================================================================
# 1) 判定：religion + has_personal_deity。<七神> = acg_mec_e_seven_archons，
#    <三月> = acg_mec_e_moon_goddess；deity key 见 common/personal_deities/00_acg_mec_e_deities.txt
# 2) 频率：mean_time_to_happen = { months = 120 }，即持有该神后按 10 年 MTTH 判定。
#    全部不加 fire_only_once —— 冷却过去后同一事件可再次触发。
# 3) 防连跳（共用互斥 flag）：
#      immediate 里 set_country_flag = acg_mec_e_had_deity_event_flag
#      trigger   里 acg_mec_e_deity_event_gate = yes（查 flag，定义在
#                common/scripted_triggers/acg_mec_e_archon_triggers.txt）
#      after     里 clr_country_flag = acg_mec_e_had_deity_event_flag
#    语义：任意一件信仰事件在场时，其余 29 件一律不判定。
# 4) 为什么 gate 不是单纯 NOT = { has_country_flag }：
#    set_country_flag 的签名是 <string>（不是 block），写不了 days 过期参数
#    —— 见 EU4 文档 effects.txt:47「set_country_flag = <string>」。
#    共用 flag 一旦遇上 after 未执行（读档中断 / 事件被其他途径关闭）就会永久挂着，
#    整个 mod 的 30 件信仰事件全停。故 gate 用 OR 兜底：flag 已挂满 30 天仍未清，
#    视为漏清、允许重新判定，最坏情况只是某件事件多弹一次。
# 5) 效果里"全国叛乱 +1 · 10 年"这类代价走 acg_mec_e_unrest_10y 修正。
# ============================================================================
