#       trigger = { tag = ENG } + free = yes		#will be added at load.
#   WIKI_VERIFIED：理念组修改.html §国家理念组 ——「国家理念组在加载游戏时即被确定……
#     国家理念组代码中要有 free = yes 这一行，用于和基本理念组进行区别」。
#
# 【结构】传统 start + 野心 bonus + 7 条理念 —— 与原版 ENG_ideas 同形。
#
# 【平衡口径】对标本 mod 已有的 YYK / ALC：
#   · YYK（common/ideas/YYK_ideas.txt，组名 ACG_MEC_EX_YYK_ideas）
#       传统 land_morale 0.10 + global_manpower_modifier 0.25；野心两项；理念数值 0.10~0.20
#   · ALC（common/ideas/ALC_ideas.txt）
#       传统 mercenary_cost -0.25 + available_mercenary_companies 1.0；理念数值 0.10~0.25
#   本组走「学者共和国」路线：经济 / 科技 / 理念花费偏强，军事只占 1 条，且不设军事野心。
#
# 【键名证据】下列 modifier 键全部在原版 common/ideas/00_country_ideas.txt 中有实例：
#   development_cost(:36)        reform_progress_growth(:537)   core_creation(:85)
#   idea_cost(:1041)             global_tax_modifier(:82)       stability_cost_modifier(:345)
#   technology_cost(:118)        global_institution_spread(:758) production_efficiency(:157)
#   global_trade_goods_size_modifier(:133)  prestige(:436)      republican_tradition(:99)
#   ae_impact(:705)              province_warscore_cost(:1283)  land_morale(:476)
#   infantry_power(:255)         leader_land_shock(:319)
